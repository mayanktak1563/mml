# YouTube AdBlocker Chrome Extension Icons

This directory should contain the following icon files:
- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels) 
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

For now, these are placeholder files. To use the extension, you'll need to add actual PNG icon files in these sizes.

The icons should represent a YouTube ad blocker - suggestions:
- Red circle with a line through it (classic "block" symbol)
- YouTube logo with an "X" or block symbol
- Shield icon representing protection

You can create these icons using:
- Online icon generators
- Image editing software like GIMP, Photoshop
- Vector graphics software like Inkscape

The icons should be:
- Clear and recognizable at small sizes
- Red/black color scheme to match the blocking theme
- Professional looking for Chrome Web Store submission
